# Privacy

This plugin collects no data and sends nothing anywhere.

- **Reads:** the `TDD_GATE` environment variable, and the local Claude Code session transcript, only to check whether the test-driven-development skill was invoked.
- **Writes:** nothing.
- **Sends:** nothing. The plugin makes no network calls.
- **Retains:** nothing. Each check runs and exits.

The skill itself is instructions for Claude and runs no code.
